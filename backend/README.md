# 后端（规划中）

本目录用于独立后台 API 服务。当前尚无后台实现；前端现阶段仅为 Sites 静态演示页面，动物数据仍写在 `frontend/app.js` 中。

## 首期边界

- 提供自助注册、账号密码登录与退出；密码只存储安全哈希，认证令牌和会话策略待技术方案确定。
- 提供动物档案的查询、创建、编辑、下架和照片管理接口。
- 提供已登录用户提交领养申请、查看本人申请状态的接口。
- 主负责人、负责人权限相同，可查看和处理申请、创建或停用志愿者账号。
- 志愿者仅能管理动物档案，不得读取领养申请和申请人联系方式。
- 申请首期收集姓名、手机号、居住地、养宠经验和申请理由；不收集身份证号码。

## 可迁移要求

- 业务规则放在服务自身，避免直接依赖单一云厂商的身份、数据库或对象存储专有能力。
- 数据库需提供可重复执行的迁移脚本和定期导出/恢复说明。
- 照片存储通过适配层访问，元数据记录对象键；支持批量导出和切换存储后端。
- 密钥仅通过部署环境的安全配置提供，禁止提交到 Git。
- 初始测试使用虚构数据；建立权限检查，确保志愿者无法读取申请数据。

## 待确定

正式实现前需在 GitHub Issue #1 确认后端语言/框架、数据库、会话方案、密码找回方式、阿里云产品配置、备份周期和 API 规范。
