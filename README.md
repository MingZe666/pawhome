# 爪爪有家

面向流浪动物救助与领养的个人项目，前后端独立组织：

- `frontend/`：Sites 网站导出的静态页面与示例图片。
- `backend/`：ASP.NET Core 10 / Identity Cookie / MySQL API、配置、测试与迁移说明。

## 产品规则

访客浏览已上架动物；用户自行注册账号，以账号密码登录。同一账号可发布动物，也可申请别人的动物。求助人只管理自己发布的档案，最多同时上架 **3 只**，草稿不占名额，下架释放名额。

申请包含姓名、手机号（必填）、微信号（选填）、居住地、养宠经验和申请理由，不收集身份证号。联系方式仅申请人本人与对应动物的发布者可见，双方私下联系。没有负责人或志愿者角色。

## 当前状态

前端仍为使用示例数据的静态演示，账号、发布、收件箱和申请页面接入由 Issue #2 跟踪。后端开发在 PR #5 中，待审核合并；现有前端尚不能完成真实领养流程。

## 开发与部署

- 目标用户在中国大陆；先做测试版，公开上线前评估阿里云大陆节点、域名和个人主体备案条件。
- 月度云服务预算目标不超过人民币 300 元。
- 数据库地址由配置决定；测试、生产环境分别配置，代码、数据库和照片可备份、导出和迁移。
- 密钥和凭据不提交仓库；测试使用虚构动物与申请人信息。
