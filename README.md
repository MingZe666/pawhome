# 爪爪有家

面向流浪动物救助与领养的个人项目，前后端独立组织：

- `frontend/`：保留 Sites 页面视觉的原生模块网站，调用真实 API，包含开发代理与浏览器联调测试。
- `backend/`：ASP.NET Core 10 / Identity Cookie / MySQL API、配置、测试与迁移说明。

## 产品规则

访客浏览已上架动物；用户自行注册账号，以账号密码登录。同一账号可发布动物，也可申请别人的动物。求助人只管理自己发布的档案，最多同时上架 **3 只**，草稿不占名额，下架释放名额。

申请包含姓名、手机号（必填）、微信号（选填）、居住地、养宠经验和申请理由，不收集身份证号。联系方式仅申请人本人与对应动物的发布者可见，双方私下联系。没有负责人或志愿者角色。

## 当前状态

前端已连接真实后端：注册登录、邮箱验证与密码找回、动物档案与照片管理、申请提交与收件箱。数据库与 Cookie 全流程在隔离测试环境验证，尚未公开部署；Issue #2 跟踪前端交付。

## 前端启动

需要 Node.js 22+。在包含 `frontend/package.json` 的代码分支中，从仓库根目录运行：

```powershell
cd frontend
npm ci
npm run dev
```

未配置证书时访问 `http://localhost:5173`。完整注册登录联调需要前端 HTTPS 及运行中的后端；[前端 README](frontend/README.md) 提供证书准备、两个终端启动步骤和常见问题。无需先构建页面。

## 开发与部署

- 目标用户在中国大陆；先做测试版，公开上线前评估阿里云大陆节点、域名和个人主体备案条件。
- 月度云服务预算目标不超过人民币 300 元。
- 数据库地址由配置决定；测试、生产环境分别配置，代码、数据库和照片可备份、导出和迁移。
- 密钥和凭据不提交仓库；测试使用虚构动物与申请人信息。

详见 [前端说明](frontend/README.md)、[后端说明](backend/README.md) 和 GitHub Issue #1。
