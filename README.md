# 爪爪有家

面向流浪动物救助与领养的独立项目。仓库按前后端分离组织：

- `frontend/`：当前 Sites 网站导出的静态前端页面与图片。
- `backend/`：后台服务边界与接口约定文档；后台代码尚未实现。

## 当前状态

前端是可独立运行的静态演示站，动物档案使用示例数据，不包含账号注册、登录、申请提交或管理后台。正式功能应由独立后端提供 API，再由前端通过配置的 API 地址调用。

首期计划支持访客浏览、自助账号密码注册和登录、登录后提交领养申请。志愿者仅管理动物档案；主负责人和负责人权限相同，并可管理志愿者账号及查看申请。

## 开发与部署原则

- 目标用户在中国大陆；先开发测试，公开上线前评估阿里云大陆节点、域名和 ICP 备案条件。
- 月度云服务预算目标不超过人民币 300 元。
- 代码、数据库和照片应可备份、导出和迁移；密钥不提交到仓库。
- 测试不得使用真实申请人个人信息。
