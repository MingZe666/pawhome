# 前端（Sites 静态页面）

这里保存此前「爪爪有家」Sites 网站可获取到的静态发布源文件，拆入仓库时保持现有页面与交互，不包含 Sites 的部署凭据或私有项目配置。

## 文件

- `index.html`：页面结构与中文内容。
- `styles.css`：响应式样式。
- `app.js`：示例动物档案、筛选、详情弹窗、领养指南和分享交互。
- `assets/`：当前页面使用的示例动物照片。

可通过任意静态 HTTP 服务预览此目录。页面当前使用本地示例数据，尚未实现账号注册、登录、真实动物数据、领养申请提交或后台管理。接入后端时，由前端调用 `../backend` 定义的 API；部署环境中的 API 地址应配置化，不能把密码或服务密钥写入前端代码。

图片来源和作者致谢在页面「图片致谢」中列出。
